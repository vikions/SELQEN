# SELQEN design system

Operate mode: a compact inspection panel used next to a trading page. Preserve the user's existing context and keep the result readable at 360px wide. The demo lab provides a wider controlled workbench, not a second product dashboard.

Direction fixed by the approved brief: precision financial review. Cool off-white surface, graphite text, dark forest green identity; amber and red reserved for semantic warnings. No glowing effects, ornamental graphs or decorative motion. Geist local font; monospace only for addresses and measured data. 4/8px spacing rhythm, 12px controls, clear 1px dividers. A geometric open-square wordmark suggests inspecting a bounded region.

Verdict is the first meaningful content. Reasons precede evidence. Metadata is expandable. Status always uses text and icon in addition to color. Visible keyboard focus, semantic labels, reduced-motion support. Button press feedback only; animation does not imply ongoing verification.

Demo provenance remains above the result and in every export. Live and fixture labels never rely on color alone. The broad lab uses an asymmetric two-column composition with a narrow full-height panel on the right and controlled scenario interaction on the left; below 900px it becomes one column.
